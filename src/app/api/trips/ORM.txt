# Database polyfills

Prisma Client provides features that are not achievable with relational databases. These features are referred to as "polyfills" and explained on this page.
Prisma Client provides features that are typically either not achievable with particular databases or require extensions. These features are referred to as polyfills. For all databases, this includes:
- Initializing [ID](https://pris.ly/docs/orm/prisma-schema/data-model/models#defining-an-id-field) values with cuid and uuid values
- Using [@updatedAt](https://pris.ly/docs/orm/prisma-schema/data-model/models#defining-attributes) to store the time when a record was last updated
[ID](https://pris.ly/docs/orm/prisma-schema/data-model/models#defining-an-id-field)

```
cuid
```


```
uuid
```

[@updatedAt](https://pris.ly/docs/orm/prisma-schema/data-model/models#defining-attributes)

```
@updatedAt
```

For relational databases, this includes:
- [Implicit many-to-many relations](https://pris.ly/docs/orm/prisma-schema/data-model/relations/many-to-many-relations#implicit-many-to-many-relations)
[Implicit many-to-many relations](https://pris.ly/docs/orm/prisma-schema/data-model/relations/many-to-many-relations#implicit-many-to-many-relations)
For MongoDB, this includes:
- [Relations in general](https://pris.ly/docs/orm/prisma-schema/data-model/relations) - foreign key relations between documents are not enforced in MongoDB
[Relations in general](https://pris.ly/docs/orm/prisma-schema/data-model/relations)
